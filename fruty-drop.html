Project Overview

A fruit-themed puzzle game with colorful fruit, varied level layouts, and color-coded collection slots. Explore four level previews and a gameplay recording.

My Contributions

  • Developed core gameplay systems and level mechanics using Unity and C#.
  • Implemented fruit interactions, crushing and sorting logic, and physics behavior.
  • Built a custom Level Editor for creating and configuring game levels.
  • Managed game configuration and level data with ScriptableObjects.
  • Implemented UI flows and gameplay animations.
  • Designed and implemented sand effects and other gameplay VFX.
  • Optimized game performance for smoother gameplay and more stable frame times.
  • Used Git for version control throughout development.
  • Integrated third-party SDKs into the game.
